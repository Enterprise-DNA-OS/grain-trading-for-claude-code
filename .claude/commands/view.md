---
description: Render the dashboards as printable pages: the week, the position and prices, and money in and out.
---

1. Run `npm run view` (all) or `npm run view -- week`, `npm run view -- position`, `npm run view -- money`.
2. Files land in `views/<name>.html`. Open the one asked for and summarise what it shows in three lines.
3. For a new page, use /new-view.
