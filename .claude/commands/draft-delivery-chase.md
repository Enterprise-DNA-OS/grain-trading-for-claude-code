---
description: Draft a note to a grower behind on a purchase contract: tonnes delivered, tonnes still owed, the window, and what happens next.
---

1. Run `npm run grain -- contract <number> --json` and `npm run grain -- org <grower> --json` (read the notes: there may be a reason, like a header down).
2. Write `drafts/delivery-<number>-<grower>.md`: the contract, tonnes contracted and delivered, tonnes short against the tolerance, the window and when it closed, and a plain ask for a date for the rest.
3. Be fair and factual. Never threaten a wash-out, a default or a price difference unless the operator names it and the contract terms support it; if they do, quote the contract.
4. Never send it. A person reads it and sends it.
