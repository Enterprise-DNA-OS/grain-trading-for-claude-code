description: A dated note on a grower, buyer or contract: a call, a promise, a reason for a delay.

1. Run `npm run grain -- log <name, code or contract number> "the note"`.
2. Say back where it went. Notes show on /who and on the contract card.
3. If the note contains a promise with a date ("rest of the barley after the 5th"), offer to check that date in the next weekly review.
